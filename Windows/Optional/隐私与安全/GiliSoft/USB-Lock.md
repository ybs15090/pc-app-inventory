# GiliSoft USB Lock

## 软件简介

USB Lock 是一款 Windows 端点设备控制工具，用于限制电脑可以接入或使用哪些移动存储、手机及其他外接设备。它适合共享电脑、办公终端、实验室或前台设备等需要降低可移动介质数据外带风险的场景。

## 主要功能

- 阻止未知 U 盘、移动硬盘、SD 卡和部分非系统分区的读写访问。
- 通过可信设备白名单保留已批准的公司设备。
- 限制手机文件传输、USB 网络共享、光盘介质、蓝牙、打印机及部分端口类别。
- 记录允许、拒绝和白名单相关事件，便于检查设备访问情况。
- 附带网站和程序限制等额外控制项，并提供设置自保护。

## 安装方法

1. 从[官方产品页](https://www.gilisoft.com/product-usb-lock.htm)下载试用版。
2. 使用管理员权限在测试电脑上安装，设置管理密码与恢复方式。
3. 在启用拦截规则前，记录键盘、鼠标、打印机、手机、读卡器和工作 U 盘等现有设备需求。

## 基本使用

1. 先把必须使用的公司 U 盘或外接设备加入可信白名单。
2. 只启用一个小范围规则，例如先阻止未知 USB 存储，验证日常设备不受影响。
3. 分别测试批准设备、未知设备、读写行为和管理员解锁流程。
4. 检查日志是否正确记录允许和拒绝事件。
5. 导出或记录白名单和策略，在测试稳定后再逐台部署。

## 使用边界与注意事项

- **USB Lock 不加密 U 盘中的文件**。它控制的是安装了该软件的电脑能够使用哪些设备；U 盘丢失后的数据保护应使用 [USB Encryption](USB-Encryption.md) 或其他卷加密方案。
- 广泛封锁设备类别可能影响手机、打印机、蓝牙、读卡器、调制解调器或维护工具。应逐类启用并保留可用的管理入口。
- 不应在没有现场恢复手段的远程主机上一次性启用所有限制，以免误拦截维护设备或造成管理锁定。
- 白名单和日志能辅助执行策略，但不能替代 Windows 账户权限、终端防护、网络审计和组织的数据管理制度。
- 在公司或学校环境部署前，应明确授权、告知和日志保留规则，确保符合内部政策及适用法规。

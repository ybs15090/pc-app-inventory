# GiliSoft File Lock Pro

## 软件简介

File Lock Pro 是一款面向 Windows 文件、文件夹、驱动器、移动存储和局域网共享目录的访问控制工具。它把“隐藏”“锁定”“防修改”和“加密”放在同一个界面中，适合只保护部分数据、不需要加密整个磁盘的场景。

## 主要功能

- **隐藏**：让指定文件、文件夹或驱动器不出现在日常浏览和常规搜索中。
- **锁定**：通过主密码限制读取或打开指定对象。
- **防修改**：允许查看内容，但限制写入、删除、移动或重命名。
- **文件加密**：创建受密码保护的 GFL 文件或可执行封装，用于存储或传递。
- **外部与共享目录保护**：可对 U 盘、移动硬盘及受支持的局域网共享目录应用规则。
- **辅助工具**：包括文件粉碎、目录变化监控、自保护和恢复邮箱等功能。

## 安装方法

1. 从[官方产品页](https://www.gilisoft.com/product-file-lock-pro.htm)下载试用版安装包。
2. 安装后设置强主密码，并在正式保护数据前配置可用的恢复邮箱。
3. 先用临时测试目录验证锁定、解锁、重启后访问和卸载流程。

## 基本使用

1. 备份准备保护的原始数据。
2. 根据数据位置选择本地磁盘、外部磁盘或共享目录。
3. 根据目标选择隐藏、锁定或防修改；若需要真正的密文输出，应使用文件加密功能。
4. 添加测试文件并应用规则，然后从资源管理器验证打开、修改、移动和删除行为。
5. 确认恢复方式可靠后，再逐步加入正式数据。

## 使用边界与注意事项

- **隐藏、锁定和防修改不等同于加密**。它们主要依赖本机软件的访问控制；设备丢失或数据需要离开本机时，应优先使用加密输出或整盘加密方案。
- File Lock Pro 不替代 BitLocker：前者适合针对具体文件和目录设置规则，后者面向整个卷的数据静态保护。
- 可执行加密封装可能被邮件系统、应用白名单或安全软件拦截，向他人交付前要在目标环境实际测试。
- 文件粉碎属于不可逆操作，必须逐项复核目标路径；它也不能代替正常的生命周期和备份策略。
- 忘记主密码或错误启用隐身模式可能增加恢复难度，因此应先配置恢复邮箱并保存独立备份。

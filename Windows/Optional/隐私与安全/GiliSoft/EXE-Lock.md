# GiliSoft EXE Lock

## 软件简介

EXE Lock 是一款 Windows 应用启动控制工具。它可以对传统桌面 EXE 程序和受支持的 Microsoft Store/UWP 应用设置“直接阻止”或“密码验证”策略，适合共享家庭电脑、办公终端、教室、实验室和前台设备。

它控制的是程序能否启动，不会加密程序文件，也不会自动保护程序内部保存的数据。

## 主要功能

- **桌面程序控制**：将 EXE 文件、快捷方式、浏览器、游戏、财务软件或管理工具加入保护列表。
- **Store 应用控制**：对受支持的 Microsoft Store/UWP 应用设置启动限制。
- **两种策略**：直接阻止程序启动，或在启动前要求输入放行密码。
- **临时解锁**：在维护、演示或临时授权期间暂停部分限制。
- **应用白名单**：排除可信程序和系统关键组件，降低误拦截风险。
- **拦截日志**：查看受保护目标、启动拦截和近期尝试记录。
- **恢复设置**：可配置恢复邮箱，并支持面向自动化管理的命令行操作。

## 安装方法

1. 从[官方产品页](https://www.gilisoft.com/product-exe-lock.htm)下载试用版。
2. 在需要控制应用启动的 Windows 电脑上安装，设置强管理密码和可用的恢复邮箱。
3. 首次测试只选择一个非系统、非安全关键程序，不要立即锁定文件资源管理器、设置、登录组件或远程维护工具。

## 基本使用

1. 在 Desktop Apps 或 Store Apps 中添加目标应用，并核对显示名称、可执行文件路径或应用标识。
2. 需要完全禁止时选择“直接阻止”；需要由管理员临时批准时选择“密码验证”。
3. 从开始菜单、快捷方式、安装目录和文件关联等入口分别启动程序，确认规则都能按预期生效。
4. 测试正确密码、错误密码、临时解锁和重启后的行为。
5. 检查拦截日志，并确认管理界面、恢复邮箱和卸载流程仍然可用。

## 命令行使用

官方指南提供 `ExeLock.exe` 的 `/lock`、`/unLock` 和 `/run` 等参数，可用于脚本化锁定、解锁或运行指定程序。命令行中直接传递密码可能被命令历史、日志或进程检查工具看到，因此不应在共享脚本中明文保存真实管理密码；批量部署前也应先确认当前版本的参数格式。

## 使用边界与注意事项

- EXE Lock 是本机应用启动控制，不是文件加密、沙箱或恶意软件防护。程序的数据文件仍需使用账户权限或加密工具保护。
- 同一程序可能存在启动器、辅助进程、便携副本或更新后变化的路径。应测试所有入口，并在升级程序后复查规则。
- 锁定系统组件、安全软件、远程控制工具或 EXE Lock 自身依赖项可能导致维护困难。使用白名单，并始终保留本地管理员恢复路径。
- 密码验证适合在共享电脑上增加一道应用级门槛，但不能替代独立 Windows 账户和最小权限配置。
- 日志可能包含用户和应用使用行为；多人或组织环境中应提前明确查看权限与保留期限。

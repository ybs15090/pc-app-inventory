# GiliSoft Private Disk

## 软件简介

Private Disk 用于创建密码保护的加密虚拟磁盘。受保护内容集中保存在 `.gpd` 容器中；需要使用时将容器解锁并挂载为盘符，完成工作后再卸载，使文件不再以普通目录形式暴露。

官网目前将 AES-256 加密、隐藏磁盘映像、便携私密盘和多容器挂载列为核心能力。它适合把文档、证件扫描件、项目资料或归档文件集中放在一个独立的加密空间中。

## 主要功能

- 创建一个或多个 `.gpd` 加密容器，并分别设置用途和容量。
- 解锁后像普通磁盘一样读写，关闭后恢复为加密容器。
- 容器可保存在本地磁盘、移动介质或受控的同步目录中。
- 支持便携私密盘、隐藏或伪装文件夹以及密码钱包等辅助功能。
- 可用多个容器区分个人、财务、客户或项目数据。

## 安装方法

1. 从[官方产品页](https://www.gilisoft.com/product-private-disk.htm)下载试用版并安装。
2. 设置主密码和恢复信息。
3. 先创建小容量测试容器，验证挂载、写入、卸载和重新打开流程。

## 基本使用

1. 选择本地或便携场景，新建 `.gpd` 容器并设置足够强的密码。
2. 挂载容器，在出现的虚拟盘符中写入测试文件。
3. 关闭正在访问文件的程序，再卸载私密盘。
4. 重新挂载并检查测试文件是否完整。
5. 对容器文件建立独立备份，确认可恢复后再存入正式数据。

## 使用边界与注意事项

- 私密盘挂载期间，文件会对当前 Windows 会话和获准运行的程序开放；它不能防御已经控制该会话的恶意软件。
- 备份时应复制完整且已正常卸载的容器。容器损坏会同时影响其中多个文件，因此不能只保留一份 `.gpd` 文件。
- “隐藏”或“伪装”只是降低可见性，不应被当作加密。敏感数据应确认实际存放在加密容器内。
- 把大型容器放入云同步目录前，应测试同步、版本保留和冲突处理；不要让多台电脑同时写入同一个已挂载容器。
- Private Disk 适合集中建立一个加密工作区；若需要分别锁定原位置中的文件和目录，应使用 [File Lock Pro](File-Lock-Pro.md)。

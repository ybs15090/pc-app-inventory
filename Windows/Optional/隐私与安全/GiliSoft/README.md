# GiliSoft

<img src="../../../../.media/png/GiliSoft.png" width="130" height="60" alt="gilisoft-logo">
GiliSoft 官网将其介绍为一家创立于 2005 年的 Windows 软件公司。早期产品以文件保护和加密工具为主，之后逐步扩展到数据防泄漏、影音处理、图像与 PDF、系统维护和 AI 工具等领域。

这类工具大多围绕单一任务设计，产品名称相近但保护对象并不相同。选择前应先明确要保护的是文件、加密容器、移动介质、程序启动权限，还是电脑上的外接设备。

## 软件系列

| 系列 | 主要用途 | 代表产品 |
|------|----------|----------|
| 加密工具 | 保护文件、移动介质、光盘、视频或整个磁盘 | File Lock Pro、USB Encryption、Secure Disc Creator、Full Disk Encryption |
| 隐私与数据防泄漏 | 控制文件传播、设备接入、程序运行和使用痕迹 | DRM Protection、Copy Protection、USB Lock、Private Disk、Privacy Protector、EXE Lock、WebLock |
| 影音工具 | 录屏、剪辑、转换、音频处理和光盘制作 | Screen Recorder、Video Editor、Video Converter、Audio Toolbox |
| 图像与文档工具 | 编辑或转换图片、PDF 和 Office 文档 | Image Editor、PDF Editor、PDF Converter、Document Converter |
| 系统与 AI 工具 | 数据恢复、系统修复、RAM Disk 和 AI 辅助处理 | Data Recovery、Total Repair、RAMDisk、AIKit、FaceSwap |

官网同时提供单独产品、部分免费简化版和多种 Toolkit 套件。套件包含范围和授权方式可能调整，购买前应以产品页及结算页面的实时信息为准。

## 本目录详细介绍

| 需求 | 对应软件 | 关键区别 |
|------|----------|----------|
| 锁定、隐藏或加密指定文件和文件夹 | [File Lock Pro](File-Lock-Pro.md) | 面向具体文件、文件夹、驱动器和局域网共享目录 |
| 在 U 盘或移动硬盘上建立加密区 | [USB Encryption](USB-Encryption.md) | 同一介质可划分公开区与密码保护的加密区 |
| 建立可挂载的加密虚拟磁盘 | [Private Disk](Private-Disk.md) | 使用 `.gpd` 容器集中保存敏感文件 |
| 限制电脑可以使用哪些 USB 或外接设备 | [USB Lock](USB-Lock.md) | 控制设备接入和数据通道，本身不加密 U 盘内容 |
| 阻止或密码保护指定程序的启动 | [EXE Lock](EXE-Lock.md) | 控制桌面程序和受支持的 Microsoft Store 应用启动 |

若目标是保护整个系统盘，应另行比较 Windows 自带的 BitLocker 与 GiliSoft Full Disk Encryption；这类方案涉及启动和分区，部署风险明显高于文件级工具，不应直接在唯一一份数据或主力电脑上试验。

## 安装与购买建议

1. 只从 GiliSoft 官网产品页或官方下载中心获取安装包，避免第三方下载站的重打包版本。
2. 先使用试用版和非关键数据验证功能、Windows 版本兼容性、解锁流程及卸载流程，再决定购买或正式部署。
3. 加密、隐藏、设备拦截和程序拦截都可能导致正常访问受阻。配置前建立独立备份，并提前设置恢复邮箱或其他恢复方式。
4. 密码、恢复信息和许可证资料应离线保存；不要只保存在被同一软件保护的磁盘或文件夹中。
5. 加密不能代替备份。重要数据至少保留一份不依赖该软件即可恢复的受控备份。
6. 厂商页面是功能和兼容性信息的主要来源，但对于高价值或合规数据，还应自行验证加密实现、更新维护和组织政策是否满足要求。
7. 建议支持正版,详情见`release`中的`GiliSoft-Keygen.7z`。

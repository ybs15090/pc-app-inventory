# GiliSoft USB Encryption

## 软件简介

USB Encryption 用于保护 U 盘、存储卡和外接 USB 硬盘中的敏感数据。它可以在同一移动介质上建立普通公开区和密码保护的加密区：公开区用于日常共享，加密区解锁后以虚拟盘符显示。

## 主要功能

- 在移动介质上创建密码保护的加密区，同时保留普通公开区。
- 解锁后通过虚拟盘符读写受保护文件，关闭后隐藏加密区内容。
- 支持只读方式打开加密区，适合查看资料而不允许修改的场景。
- 提供密码管理、代理程序恢复和相关维护工具。
- 适合携带工作文档、客户资料、旅行数据和受控备份。

## 安装方法

1. 从[官方产品页](https://www.gilisoft.com/product-usb-stick-encryption.htm)下载试用版。
2. 在 Windows 电脑上安装并启动软件。
3. 准备一个已完整备份、没有唯一数据副本的测试 U 盘进行首次验证。

## 基本使用

1. 完整备份移动介质中的现有文件；创建安全区涉及介质空间布局，应按可能改变数据结构的操作对待。
2. 选择正确的移动介质，设置公开区和加密区的容量，并设置强密码。
3. 解锁加密区，将少量测试文件复制到虚拟盘符中，然后正常关闭安全区。
4. 拔出并重新连接介质，验证密码解锁、只读模式和文件完整性。
5. 保存恢复所需的代理程序、密码和说明，再迁移正式数据。

## 使用边界与注意事项

- **公开区中的文件没有得到加密区的保护**，敏感内容必须确认写入解锁后的虚拟盘符。
- USB Encryption 保护的是移动介质上的数据；它不会阻止其他 U 盘接入电脑，也不会记录设备访问行为。后者应使用 [USB Lock](USB-Lock.md)。
- 目标电脑可能受到应用白名单、安全策略或无管理员权限等限制。跨电脑使用前，应在每一种目标环境验证解锁程序能否运行。
- 介质损坏、误格式化或丢失密码仍可能导致数据不可恢复。加密 U 盘不能作为唯一备份。
- 断开设备前应先关闭加密区并安全弹出，避免虚拟盘仍在写入时造成容器损坏。

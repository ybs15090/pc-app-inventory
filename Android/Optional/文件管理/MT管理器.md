## 软件简介

MT 管理器是一款 **Android 文件管理与 APK 分析、编辑工具**，以左右双窗口操作为特色，适合整理手机文件、处理压缩包、编辑文本，以及查看和修改 APK 的代码与资源。软件定位与双窗口设计见 [官网](https://mt.cc/)。

普通文件管理不要求手机拥有 Root 权限；访问系统目录等操作受 Android 权限限制。部分高级编辑和网络存储功能需要 VIP，具体范围见 [Root 说明](https://mt.cc/guide/file/root.html) 与 [VIP 功能介绍](https://mt.cc/vip/)。需要在电脑和手机之间交换文件时，也可搭配跨平台的 [LocalSend](../../../General/Optional/File-Transfer-文件传输/LocalSend.md)。

资料核对日期：**2026-10-14**。验证范围：官方网页与用户手册核对，未在本次文档整理中安装应用或进行手机功能实测。

## 安装方法

### 官方下载与版本选择

通过 [官方下载页](https://mt.cc/download/) 获取 APK。核对时最新正式版为 **v2.26.10**，发布于 **2026-10-10**；更新后以下载页显示的版本为准。

| 版本 | 适用情况 |
|---|---|
| 正式版 | 日常使用优先选择的版本。 |
| 共存版 | 包名与正式版不同，可同时安装，适合需要保留两个独立安装实例的情况。 |
| TargetSdk28 版 | 用于官网下载页说明的终端执行权限、部分 Root 挂载命名空间兼容问题；没有对应需求时使用普通正式版。 |

TargetSdk28 表示应用的目标 API 级别为 28；最低系统要求由 `minSdkVersion` 决定，见 [Android 官方 SDK 属性说明](https://developer.android.com/guide/topics/manifest/uses-sdk-element)。官方说明该版本仅从官网下载，后续通过应用内或官网下载更新，不应从应用商店更新。具体差异见 [下载页的 TargetSdk28 说明](https://mt.cc/download/#targetsdk28-说明)。

### 安装与首次授权

1. 在手机浏览器中打开官方下载页，选择版本并下载 APK。
2. 打开下载的 APK，按系统提示为本次使用的浏览器或文件管理应用允许“安装未知应用”，完成安装。不同系统的设置名称可能略有差异。
3. 启动 MT，按提示授予需要的文件或存储访问权限，再打开实际要处理的目录。
4. 如需访问受限制的目录，按应用提示完成对应授权；普通文件整理无需为了使用 MT 而专门 Root。

Android 11 及后续系统对 `Android/data` 等目录的访问有限制，具体能否访问取决于系统版本、厂商实现与当前授权方式，不能仅凭应用已获存储权限判断所有目录都可读写。相关边界见 [官方 Root 说明](https://mt.cc/guide/file/root.html)。

## 功能特点

| 功能 | 用途与限制 |
|---|---|
| 双窗口文件管理 | 同时浏览两个目录，直接在窗口之间复制、移动和提取文件；支持多选、书签与列表过滤。 |
| 压缩包处理 | 解压常见格式，创建 ZIP、7z、tar、tar.gz、tar.bz2；ZIP 内可添加、修改、重命名和删除条目。 |
| 文本编辑 | 支持多文件编辑、查找替换、语法高亮和换行符设置；格式化等功能取决于当前语法支持。 |
| APK 代码与资源处理 | 查看、编辑 APK 中的 XML、ARSC 与 Dex/Smali，提供代码和资源对比等工具；部分功能或完整编辑能力需要 VIP。 |
| Hex 编辑器 | 查看和编辑二进制内容；按官方 VIP 说明，免费用户修改后不能保存，保存需要 VIP。 |
| 网络存储 | 可连接 FTP；官方 VIP 页面另列 FTPS、SFTP、SMB、WebDAV 等功能。 |
| MCP 服务 | 向支持 MCP 的 AI 工具提供 APK、手机文件和 ZIP 操作能力；AI 工具需自行配置模型及连接。 |

功能依据：[快速入门](https://mt.cc/guide/)、[压缩文件手册](https://mt.cc/guide/file/archive-file.html)、[文本编辑器手册](https://mt.cc/guide/file/text-editor.html)、[VIP 功能介绍](https://mt.cc/vip/) 和 [MCP 服务手册](https://mt.cc/guide/ai/mcp.html)。VIP 范围与临时开放的功能可能调整，以当前应用和官方说明为准。

## 使用方法

### 双窗口复制与移动

1. 左侧打开源文件夹，右侧打开目标文件夹，例如左侧为 `Download`，右侧为自行建立的资料目录。
2. 长按源文件选择复制或移动，目标为另一侧窗口当前打开的目录；多文件操作可先左右滑动文件进入多选模式。
3. 核对目标目录与同名文件处理选项，完成后在目标窗口检查文件。
4. 常用目录可加入书签；需要让两侧定位到同一路径时使用同步按钮，再进入目标子目录。

这种操作直接从当前窗口写入另一窗口，初次使用时应先确认两侧路径。具体手势见 [官方快速入门](https://mt.cc/guide/)。

> 移动和覆盖会改变原有文件位置或内容。处理重要资料时先复制并核对结果，再整理原件。

### 压缩与解压文件

- **创建压缩包**：选中文件或文件夹，长按后选择压缩，设置格式与保存位置。
- **解压整个压缩包**：长按压缩文件，选择“解压到…”并指定目标目录。
- **提取部分内容**：点击压缩文件进入内部列表，在另一窗口打开目标目录，再按双窗口复制方式提取选中的文件。
- **更新 ZIP 内的文本**：打开包内文件编辑，保存并返回文件列表后，确认是否更新到压缩包。

APK、JAR 也采用 ZIP 容器，但修改 APK 内容后还涉及签名与运行验证，不能把普通 ZIP 更新当作完整的 APK 构建流程。操作说明见 [压缩文件手册](https://mt.cc/guide/file/archive-file.html) 与 [MCP 的 APK 签名说明](https://mt.cc/guide/ai/mcp.html)。

### 编辑文本与查看 APK

1. 编辑配置或脚本前先保留副本，再用文本编辑器打开文件，完成查找、替换或代码编辑后保存。
2. 与电脑或服务器交换文本时，按目标工具需要检查编码及 LF/CRLF 换行设置；官方说明换行符选项在写出文件时生效。
3. 点击 APK 查看信息；需要进一步分析时进入包内，按目标文件类型选择 XML、ARSC 或 Dex 编辑工具。
4. 修改自己的测试 APK 时保留原包，完成后生成并按需签名新包，再检查修改内容和实际运行情况。

文本编辑细节见 [官方文本编辑器手册](https://mt.cc/guide/file/text-editor.html)。APK 打包成功不代表应用一定能正常运行，修改后跳过签名也不意味着原签名仍然有效，参见 [官方 MCP 服务手册](https://mt.cc/guide/ai/mcp.html)。

### 连接 AI 工具的 MCP 服务

这是可选功能，用于让 AI 工具读取、分析或处理手机上的文件与 APK。ZIP 工具从 **v2.26.10** 起提供，说明见 [官方 MCP 服务手册](https://mt.cc/guide/ai/mcp.html)。

1. 在主界面的侧拉栏中打开“工具 → MCP 服务”，启动服务。
2. 在支持 **Streamable HTTP** 的 AI 工具中添加 MT 显示的完整连接地址，保留末尾的 `/mcp`。电脑连接手机时使用手机的局域网地址，并确保两台设备可互相访问。
3. 在 MCP 设置中核对 Home 目录与文件访问规则；其他目录按需授予权限。
4. 先在 Home 中放一个测试文本，让 AI 读取并概括内容，确认连接、路径和权限正确，再处理实际文件。

> 普通文件编辑和 ZIP 更新会直接修改目标；MCP 删除文件不进入回收站。修改前先备份并限定操作范围。服务应在可信网络使用，需要时启用 Bearer 令牌认证，避免直接暴露到公网。

## 常见问题

| 问题 | 说明或处理方法 |
|---|---|
| 使用 MT 必须 Root 吗？ | 普通文件整理不需要。访问 `/data` 等系统目录通常需要 Root；即使已授权，也可能因系统限制无法写入 `/system`。 |
| `Android/data` 无法进入或看不到文件 | 先核对系统的目录限制与 MT 当前授权，按应用提示处理；官方不保证所有 Android 版本都能使用相同访问方式。 |
| 为什么有些编辑功能要求 VIP？ | 免费功能与 VIP 完整功能有区别，例如 Hex 修改保存、自定义 APK 签名密钥和部分高级编辑。以官方 VIP 页面及应用提示为准。 |
| 复制后找不到文件 | 检查另一窗口操作时所在的目录；双窗口复制直接写入另一侧路径。 |
| AI 已连接但读不到目标文件 | 检查手机上的实际路径、Home 目录和 MCP 文件权限规则；电脑本地路径不能直接用来访问手机文件。 |
| 切换到后台后 MCP 连接中断 | 按 MCP 手册启用悬浮球并检查系统电池优化设置；后台策略因系统而异，不能保证服务始终不中断。 |

排查依据：[Root 说明](https://mt.cc/guide/file/root.html)、[VIP 功能介绍](https://mt.cc/vip/)、[快速入门](https://mt.cc/guide/) 和 [MCP 服务手册](https://mt.cc/guide/ai/mcp.html)。

# 说明

本文件夹收录跨平台网页浏览器，适用于日常浏览、多设备同步和不同隐私或标签管理需求。

## 清单

- [Firefox](Firefox.md) — 使用 Gecko 引擎，提供增强型跟踪保护、端到端加密同步和垂直标签页
- [Opera（含 Opera GX）](Opera.md) — 基于 Chromium，内置广告与跟踪器拦截、浏览器内 VPN、工作区和侧边栏
- [Tor Browser](Tor-Browser.md) — 基于 Firefox ESR，通过 Tor 网络路由网页流量并强化抗指纹保护
- [Vivaldi](Vivaldi.md) — 高度可定制的 Chromium 浏览器，提供网页面板、丰富的标签管理和内置生产力工具

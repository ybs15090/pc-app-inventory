# <img src="../../../.media/png/Opera.png" width="60" height="60" alt="Opera logo"> Opera

Opera 是一款基于 Chromium 的跨平台浏览器，桌面版支持 Windows、macOS 和 Linux。它在常规网页浏览能力之外，集成了广告与跟踪器拦截、浏览器内 VPN、工作区、标签页分组、侧边栏和跨设备同步等功能，适合希望减少扩展安装、集中管理大量标签页的用户。

## 适用场景

- 希望浏览器自带广告拦截、跟踪器拦截和基础隐私工具
- 经常同时处理工作、学习等多组标签页，需要使用工作区或标签页岛进行分类
- 希望通过侧边栏快速访问通讯、音乐或其他网页服务
- 需要在多台设备之间同步书签、历史记录、设置、密码和已打开标签页

## 安装

建议优先从 [Opera 官方下载页](https://www.opera.com/download)获取安装程序。该页面同时提供桌面版、移动版以及离线安装包入口。

### Windows

在官方下载页选择 **Opera for Windows**。普通用户可使用在线安装程序；需要离线部署或指定架构时，可选择 64 位、32 位或 ARM 离线安装包。

### macOS

在官方下载页选择 **Opera for macOS**，下载并打开安装包，然后将 Opera 拖入“应用程序”文件夹。

### Linux

官方下载页提供 Debian/Ubuntu 使用的 `.deb` 包、RPM 包和 Snap 包。按发行版选择对应格式安装，例如：

```bash
# Ubuntu 等支持 Snap 的发行版
sudo snap install opera

# Debian / Ubuntu：下载 .deb 后在文件所在目录执行
sudo apt install ./opera-stable_*.deb

# Fedora / RHEL：下载 .rpm 后在文件所在目录执行
sudo dnf install ./opera-stable-*.rpm
```

动态文件名中的版本号会随发布版本变化，执行命令前应确认下载到的实际文件名。

## 初次配置

1. 打开“设置”；Windows 和 Linux 可按 `Alt + P`，macOS 可按 `⌘ + ,`。
2. 在“同步”区域选择“导入书签和设置”，从原浏览器导入书签、历史记录、Cookie 或密码等数据。
3. 根据需要将 Opera 设为默认浏览器；如果浏览器内设置未生效，再到操作系统的“默认应用”中指定。
4. 在“隐私保护”中按需启用广告拦截和跟踪器拦截，并为出现兼容问题的网站添加例外。
5. 如需跨设备同步，登录 Opera 账户，并在“高级同步设置”中只选择需要同步的数据类型。

## 核心功能

| 功能 | 说明 |
|------|------|
| 广告与跟踪器拦截 | 内置过滤功能，可按网站停用或配置例外，减少广告脚本和常见跟踪行为 |
| 浏览器内 VPN | 可在设置中启用，用于改变浏览器访问网站时显示的 IP 地址和大致区域 |
| 工作区 | 将不同主题的标签页分到独立工作区，通过侧边栏快速切换 |
| 标签页岛 | 将相关标签页组织为可折叠的分组，便于管理大量页面 |
| 侧边栏 | 集中访问书签、历史记录、下载、通讯服务、音乐播放器等功能 |
| 视频弹出 | 将网页视频或视频会议画面悬浮显示，在切换标签页或应用时继续观看 |
| Opera 同步 | 通过 Opera 账户同步书签、快速拨号、历史记录、密码、设置和已打开标签页 |
| 扩展支持 | 可使用 Opera 扩展商店，并兼容采用受支持 Chromium API 的 CRX 扩展 |

## 侧边栏

Opera 的侧边栏偏向“开箱即用”的服务集成，可在浏览主页面的同时，用窄面板打开常用工具或网站：

- **工作区**：在侧边栏顶部切换工作、学习等不同标签页集合。
- **AI 与 Google 服务**：可启用 ChatGPT、Gemini、Google Calendar 和 Gmail 等入口。
- **通讯与社交**：可启用 WhatsApp、Telegram、Slack、Discord、Instagram、X、Bluesky 等预设服务。
- **Opera 功能**：可使用音乐播放器和 Flow；Flow 用于在已连接的 Opera 设备之间传送链接、文字和文件。
- **浏览器工具**：可快速访问快速拨号、书签、标签页、历史记录、下载、扩展和设置。

在右上角“轻松设置”中打开“显示侧边栏”，然后点击侧边栏底部的三个点，或者进入“设置 → 侧边栏 → 管理侧边栏”，选择要显示的项目。打开通讯服务后可将面板固定在主页面旁边，并按需开启通知徽标。

侧边栏中的 Telegram、Instagram、X 等仍是相应服务的网页版本，并非 Android 或 iOS 应用。登录方式、语音视频、文件上传和通知能力取决于网站本身及浏览器权限。

## Opera GX

Opera GX 是 Opera 面向游戏玩家推出的衍生版本，与普通 Opera 采用相近的浏览器核心，并保留广告与跟踪器拦截、浏览器内 VPN、标签页岛、工作区、分屏、Flow、音乐播放器以及通讯和社交侧边栏等主要功能。两者在本仓库中按同一款软件统计。

Opera GX 主要增加了以下游戏和个性化功能：

| 功能 | 说明 |
|------|------|
| GX Control | 可限制浏览器使用的 CPU、内存和网络带宽；可用限制项可能随操作系统和版本不同 |
| GX Mods | 可组合或制作主题、动态壁纸、界面与键盘声音、背景音乐、光标、启动动画和网页着色器 |
| GX Corner | 集中显示游戏新闻、发售日历、预告片、免费游戏和折扣信息 |
| 游戏服务集成 | 在侧边栏中突出 Twitch、Discord 等服务，便于在游戏或直播时快速查看 |
| GX Cleaner 与标签监控 | 提供更直观的缓存清理和高资源占用标签管理入口 |
| 电竞风格界面 | 默认使用更鲜明的配色、动画和声音效果，也可在设置中关闭不需要的视觉或音效 |

资源限制器的作用是为游戏或其他程序预留资源，并不等于自动提高电脑性能；限制过低可能导致网页变慢、视频卡顿或标签页重新加载。仅需要 Telegram、Instagram、X 等侧边栏服务时，普通 Opera 已经足够；需要资源限制、GX Mods 或游戏资讯时再选择 Opera GX。

Opera GX 桌面版目前支持 Windows、macOS 和 Linux，另有 Android 与 iOS 移动版，但资源限制器等桌面功能不一定出现在移动端。可从 [Opera GX 官网](https://www.opera.com/gx)下载，并在 [Opera GX 功能页](https://www.opera.com/gx/features)查看当前平台提供的功能。

## 使用提示与注意事项

- **VPN 的范围**：内置免费 VPN 主要保护 Opera 浏览器中的访问流量，不应替代覆盖整个操作系统或其他应用的 VPN 工具；可选虚拟区域也比较有限。
- **网站兼容性**：广告或跟踪器拦截可能影响登录、支付、视频播放等功能。遇到异常时，先仅对当前网站停用拦截，而不是全局关闭。
- **同步隐私**：登录同步会把所选浏览数据同步到 Opera 账户。可在高级同步设置中限制数据类型，并按需要设置独立的同步密码短语。
- **扩展安全**：安装第三方扩展前检查开发者、权限、评价与更新记录；不常用的扩展应禁用或移除。
- **更新**：Opera 默认自动更新。可打开“菜单 → 更新和恢复”手动检查版本，也可访问 `opera:about/` 查看当前版本。

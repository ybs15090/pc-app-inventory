# <img src="../../../.media/png/vivaldi.png" width="60" height="60" alt="Vivaldi logo"> Vivaldi

Vivaldi 是一款基于 Chromium 的跨平台浏览器，桌面版支持 Windows、macOS 和 Linux。它强调用户控制和深度定制，提供标签页堆叠与平铺、工作区、会话管理、网页面板、邮件、日历、RSS、笔记以及可编辑工具栏等功能，适合需要管理大量标签页或构建个人浏览工作台的用户。

## 适用场景

- 经常同时打开大量标签页，需要分组、树状查看、休眠、平铺或保存会话
- 希望把 Telegram、X、Instagram、ChatGPT、文档或监控页面等任意网站加入侧边栏
- 需要自行调整工具栏、菜单、快捷键、鼠标手势、主题和界面布局
- 希望在浏览器中整合邮件、日历、任务、RSS 阅读器和笔记
- 重视同步数据的端到端加密，并愿意妥善保管独立的加密密码或恢复密钥

## 安装

建议从 [Vivaldi 官方下载页](https://vivaldi.com/download/)获取安装程序，并根据操作系统和处理器架构选择对应版本。

### Windows

官方下载页提供 Intel/AMD 64 位、ARM64 和旧版 32 位安装程序。下载后运行安装程序；如需更改安装范围、安装位置或创建独立安装，可在安装界面中打开高级选项。

### macOS

从官方下载页获取适用于当前 macOS 的安装包，打开后将 Vivaldi 拖入“应用程序”文件夹。下载前应确认页面标注的最低 macOS 版本要求。

### Linux

官方下载页提供 Debian/Ubuntu 使用的 DEB 包，以及 Fedora/RHEL/openSUSE 等发行版使用的 RPM 包，并分别提供 x86-64 和 ARM64 架构版本。例如：

```bash
# Debian / Ubuntu：下载 DEB 后在文件所在目录执行
sudo apt install ./vivaldi-stable_*.deb

# Fedora / RHEL：下载 RPM 后在文件所在目录执行
sudo dnf install ./vivaldi-stable-*.rpm
```

动态文件名中的版本号和架构标记会随发布版本变化，执行命令前应确认实际文件名。

## 初次配置

1. 首次启动时选择界面布局、主题和标签页位置；之后仍可在设置中随时修改。
2. 进入“设置 → 导入数据”，从原浏览器导入书签、历史记录、密码和其他支持的数据。
3. 在“设置 → 隐私和安全”中按需启用跟踪器与广告拦截，并选择拦截级别。
4. 在“设置 → 同步”登录 Vivaldi 账户，设置独立的同步加密密码，并保存恢复密钥。
5. 按需启用邮件、日历和订阅源；不需要这些功能时可以保持关闭，减少界面项目。
6. 使用侧边栏的“添加网页面板”按钮，把常用网站加入面板。

## 核心功能

| 功能 | 说明 |
|------|------|
| 标签页堆叠 | 将相关标签页组成两级标签堆叠，适合管理大量页面 |
| 标签页平铺 | 在同一窗口中并排显示多个标签页，用于比较资料或同时操作 |
| 工作区与会话 | 按项目组织标签页，并将当前标签集合保存为可恢复的命名会话 |
| 网页面板 | 将任意网址放入侧边栏，以窄屏面板与主页面同时显示 |
| 界面定制 | 可编辑工具栏、菜单、主题、快捷键、鼠标手势和多种界面布局 |
| 生产力工具 | 内置邮件、日历、任务、RSS 阅读器、笔记、翻译和页面截图等功能 |
| 广告与跟踪器拦截 | 内置基于过滤列表的拦截功能，可按网站选择不拦截、仅拦截跟踪器或同时拦截广告 |
| Proton VPN | 桌面版可选择启用集成的 Proton VPN；免费方案需要账户，并限制服务器选择 |
| Vivaldi 同步 | 同步书签、部分设置、密码、历史记录、扩展、网页应用、阅读列表、标签页和笔记等数据 |
| 扩展支持 | 兼容采用受支持 Chromium API 的 Chrome 扩展 |

## 侧边栏与网页面板

Vivaldi 的侧边栏同时包含浏览器原生面板和用户自行添加的网页面板：

- **原生面板**：书签、阅读列表、下载、笔记、历史记录、窗口与标签页、翻译、会话等。
- **生产力面板**：启用相应功能后，可使用邮件、日历、任务、订阅源和联系人面板。
- **网页面板**：可输入任意网址，将 Telegram、X、Instagram、WhatsApp、ChatGPT、在线文档或状态页面等网页固定在侧边栏。

网页面板默认使用适合窄屏的移动端 User-Agent，因此许多响应式网站会呈现类似移动设备的布局。它同时支持：

- 在移动版与桌面版网页之间切换
- 为不同面板保留独立宽度和缩放比例
- 显示导航按钮，或把当前页面转到普通标签页和新窗口
- 单独静音网页面板
- 设置 1～30 分钟的定时刷新
- 为特定网页面板配置快捷键或鼠标手势

### 添加网页面板

1. 打开希望加入侧边栏的网站。
2. 在网页空白处右键，选择“将页面添加到网页面板”；也可以点击侧边栏中的“添加网页面板”按钮并输入网址。
3. 点击新增图标打开面板并完成登录。
4. 如果网站提示安装移动应用或布局异常，右键面板图标，切换为桌面版；需要窄屏布局时再切回移动版。
5. 右键面板图标可继续设置独立宽度、缩放、静音和定时刷新等选项。

网页面板运行的是网站的移动版或响应式网页，而不是真正的 Android/iOS 应用。通知、摄像头、麦克风、文件上传和扫码登录等能力取决于网站网页版本及已经授予的浏览器权限。

## 使用提示与注意事项

- **配置复杂度**：Vivaldi 的选项非常多。建议先保持默认布局，只逐步启用确实需要的面板、邮件和快捷操作。
- **同步密码**：同步数据采用端到端加密，加密密码不会发送给 Vivaldi。遗忘密码且没有任何设备保留本地数据时，可能无法恢复数据，因此应安全保存恢复密钥；同步也不应当替代正式备份。
- **VPN 范围**：集成的 Proton VPN 属于浏览器级安全网页代理，只覆盖 Vivaldi 网页流量，不覆盖其他应用，也不覆盖 Vivaldi Mail。免费版不能指定具体服务器，更多功能需要付费方案。
- **网站兼容性**：拦截功能或移动版网页面板可能影响登录、支付、音视频等操作。遇到异常时，先针对当前网站调整拦截级别或切换桌面版。
- **扩展安全**：Chrome 扩展并非由 Vivaldi 官方统一维护，安装前应检查开发者、权限、评价和更新记录。
- **更新**：Windows 和 macOS 可在“帮助 → 检查更新”中手动检查；Linux 通常随系统软件包管理器更新。官方不建议降级覆盖现有配置，因为可能损坏浏览器用户资料。

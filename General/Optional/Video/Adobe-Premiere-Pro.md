# <img src="../../../.media/png/adobe-pr.png" width="60" height="60" alt="Adobe Premiere Pro 图标"> Adobe Premiere Pro（PR）

## 软件简介

Adobe Premiere Pro（常简称 PR；Adobe 当前帮助中心多称 **Premiere**）是视频剪辑软件，也提供语音转录、字幕生成、校对、翻译和导出功能。适合在剪辑时间线内直接制作字幕。

本文依据[Adobe Premiere 帮助中心](https://helpx.adobe.com/premiere/desktop.html)整理，核对日期：2026-09-28。功能入口、支持语言与系统要求会随版本变化，使用前以当前官方文档和软件界面为准。

## 安装方法

1. 在 Adobe 官网获取并安装 [Creative Cloud 桌面应用](https://helpx.adobe.com/download-install/apps/download-install-apps/creative-cloud-apps/download-creative-cloud-desktop-app-from-web.html)。
2. 登录有使用资格的 Adobe 账号，在 Creative Cloud 中安装 Premiere。
3. 安装前核对[当前技术要求](https://helpx.adobe.com/premiere/desktop/get-started/technical-requirements/adobe-premiere-pro-technical-requirements.html)。Adobe 的 26.x 要求 Windows 11 24H2 或 macOS 14 及更新版本；旧版本的要求应查对应版本页面。

## 功能特点

- **视频剪辑**：在时间线中组织视频和音频素材，完成剪辑及导出。
- **语音转录与字幕生成**：通过 Speech to Text 将对白转为转录文本，再生成字幕轨。
- **字幕校对与翻译**：修改文字、时间和样式；当前版本提供字幕翻译功能，翻译结果仍需人工核对。
- **字幕导出**：可将字幕作为 SRT 外挂文件导出，或在视频导出时选择烧录等方式。

## 使用方法

以生成原语言字幕并导出 SRT 为例：

1. 新建项目并导入视频，可在导入时选择自动转录；已有项目可在“窗口 → 文本”中对序列执行转录。
2. 选择音频实际语言；如软件提示，先下载对应语言包。确认转录范围和目标音轨。
3. 在转录文本中校对人名、术语与漏句，再使用“从转录文本创建字幕”生成字幕轨。
4. 检查字幕分段、时间轴与画面，按需调整样式或翻译。翻译生成的新字幕轨也要逐条校对。
5. 在导出设置中选择 SRT 外挂字幕，或按交付需求选择其他字幕输出方式；导出后用播放器抽查开头、中段和结尾。

菜单名称以实际版本及界面语言为准。Adobe 官方当前说明字幕翻译会使用云服务和第三方翻译模型；处理敏感内容前应先确认素材的使用要求。

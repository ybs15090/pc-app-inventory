# Video — 音视频软件索引

这里汇总仓库中已有独立介绍的音视频软件，包含跨平台工具及 Windows 专用工具。按主要用途选择；各软件的完整介绍、安装方式和官方链接见对应页面。

## 清单

| 用途 | 软件与简介 | 适用平台 |
|---|---|---|
| 录制与直播 | [OBS Studio](OBS-Studio.md)：组合屏幕、窗口、摄像头及音频来源，录制视频或直播。 | Windows、macOS、Linux |
| 音视频转换与处理 | [Shutter Encoder](Shutter-Encoder.md)：转换、压缩、裁切音视频，提取音轨和处理字幕。 | Windows、macOS、Linux |
| 音视频转换与处理 | [格式工厂](../../../Windows/Optional/Video/格式工厂.md)：转换音视频格式，进行基础裁切、合并；也支持图片等格式。 | Windows |
| 字幕生成与编辑 | [Subtitle Edit](Subtitle-Edit.md)：编辑和同步字幕，支持语音转字幕及字幕格式转换。 | Windows、macOS、Linux |
| 字幕生成与编辑 | [Adobe Premiere Pro（PR）](Adobe-Premiere-Pro.md)：在视频剪辑时间线中转录对白、生成和校对字幕，并导出 SRT。 | Windows、macOS |
| 字幕封装 | [MKVToolNix](MKVToolNix.md)：把已制作好的字幕与音视频轨封装成可切换轨道的 MKV。 | Windows、macOS、Linux |
| 音频路由 | [VB-CABLE](../VB-CABLE.md)：把一个应用的声音送入另一个应用的录音输入。 | Windows、macOS |

此索引列的是**仓库中已有独立软件介绍的条目**；其他文档中顺带提及的工具未计入。
